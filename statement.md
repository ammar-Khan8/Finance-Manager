# Problem Statement

Many people track money in scattered spreadsheets or not at all, which makes it hard to see where income goes and whether monthly category budgets are being respected.

This project is a command-line personal finance manager that lets a user:

1. Register and log in securely (passwords are salted and hashed).
2. Record income and expenses, list them with a running balance, filter by month, and delete entries.
3. Set a monthly budget per category, receive alerts when spending exceeds it, and view monthly totals with a category breakdown chart.

Scope: single machine, command-line only, data stored in CSV files. Out of scope for this version: bank sync, multi-currency, a graphical interface, and a database.
